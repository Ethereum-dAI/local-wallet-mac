# Code of Conduct

This project follows a simple standard: be direct, technical, and respectful.

Expected behavior:

- keep discussion focused on the code, docs, security model, and developer experience
- assume good intent while asking for concrete evidence and reproducible details
- give feedback that helps move the project forward
- avoid harassment, personal attacks, or discriminatory language

Maintainers may moderate issues, discussions, or pull requests that do not meet this standard.
