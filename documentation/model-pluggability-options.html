Your call

1 · Which direction?

  • A now, C later
  • C directly, shipped in A → B order
  • B — Ollama is the point

2 · Ollama scope

  • Loopback only (127.0.0.1)
  • Any host, with a warning
  • Any host + optional API key

3 · Unverified GGUFs

  • Warn once, allow anything public
  • Checksum must come from repo metadata, else block
  • Allowlist of repos

4 · Switching models

  • Hot swap — unload, reload, keep the chat
  • Restart required (like the context window today)

5 · Curated extras

  • Gemma only, everything else is custom
  • Gemma + 2 pinned alternatives we've tested for tool calls

6 · Gated / private repos

  • Out of scope — public repos only
  • Optional HF token in Keychain
