Open decisions

Fit thresholds

  • 80% of budget = Fits, over budget = Won't fit
  • Stricter 70%, matching the common Mac rule of thumb

Test depth

  • Load only
  • Load + one tool-call round trip
  • Load + tool call + tokens/sec

On out of memory

  • Step the context down automatically, then say so
  • Ask before retrying

Curated extras

  • Gemma only; everything else is custom
  • Gemma + 2 pinned alternatives we've tested for tool calls

Gated / private repos

  • Out of scope — public repos only
  • Optional Hugging Face token in the Keychain

Found en route

  • Gemma's maxContextTokens is pinned at 32 768; the GGUF and the Hub both say 131 072
